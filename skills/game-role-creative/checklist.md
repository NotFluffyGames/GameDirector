# Creative: review checklist

Mark each line `ok`, a note, or `not-assessed` with the reason. Measured lines come first and can be `blocking`; judged lines are `advisory` unless anchored to a label, a chosen reference or a vision rule the build contradicts.

## Measured

- Each invariant's observable test, run on the captures and the event log: pass or fail, with the path.
- Every `north_stars.creative` reference still named by the vision page, and `invariants` equal to the page's list.
- A capture exists for each core moment the target covers; a missing one is a request for another capture round, not a pass.

## Judged

- Cohesion: do the visuals, feedback, words and rules of this build pull the same way, against the invariants?
- Distinctiveness: set a fresh capture beside the genre default and beside the references. Does it read as this game? Say what in the capture shows it.
- Pillar proximity: does each new thing serve a pillar or an invariant, or is it glued on?
- First-build rule: if nothing is found, list what you compared.

## Needs the person

- Whether it reads as theirs: asked at the slice verdict, with the captures beside the references.
- Calibration labels for taste: until they exist, taste judgments here are `not-assessed`.
