# Topic map

The first-level topics ideation seeds under `T1`. Seed one per row this game needs, worded for this game (not the generic question below), with the page it will write. Skip rows the vision rules out, and add rows for anything the vision raises that the map lacks.

| Area | Typical question | Priority | Page |
| --- | --- | --- | --- |
| Core loop | What exactly happens, step by step, in one cycle of the core loop, and what decision does the player make each time? | core | `wiki/mechanics.md` |
| Rules | What are the objects, actions, win and fail conditions, and how are ties, timeouts and simultaneous actions resolved? | core | `wiki/mechanics.md` |
| Controls | Which input actions exist, how are they bound per device, and how do they feel? | core | `wiki/controls.md` |
| Each system the vision names | What does this system do, what are its knobs, and which other systems does it change? | support | `wiki/systems/<system>.md` |
| Progression | What does the player gain across a session and across sessions? | support | `wiki/systems/progression.md` |
| Difficulty and AI | How is challenge set and adapted; what do opponents or enemies do? | support | `wiki/systems/ai.md` |
| Each content type | What kit pieces build it, how many pieces, and what makes two pieces play differently? | support | `wiki/content/<type>.md` |
| Modes and sessions | Which modes exist, how does a session start, flow and end, and how do sessions connect? | support | `wiki/modes.md` |
| Screens and onboarding | What is the screen flow from launch to quit, and how does a new player learn the core verb in the first minute? | support | `wiki/screens.md` |
| Feel | What feedback does each core action get, and how fast? | support | `wiki/feel.md` |
| Art and audio direction | What are the palette, shapes, camera, UI tone and audio mood, precisely enough to generate assets from? | support | `wiki/art.md` |
| Multiplayer and netcode | Local or networked; if networked, which model? | core when networked | `wiki/systems/netcode.md` |
| World and narrative | How much setting or story does the game show, and where? | later | `wiki/world.md` |

Brainstorm then works each topic through with the user and breaks it down further, one topic per conversation.
