# Feel: living page

The page is `feel` (area Feel): one sheet per core action, and no other page. One sheet per action; keep the page under the wiki's split rule.

```markdown
### <action>

- Intent: <one or two adjectives, tied to a pillar>
- References: <title mm:ss> · <title mm:ss> (1-3 clips)
- Timings (frames at the game's fixed rate): first visible response <n>; wind-up <n>; active <n>; recovery <n>; cancel from <n>
- Input windows: buffer <n> frames; forgiveness (coyote or grace) <n> frames
- Feedback layers: animation, effect, sound, camera, hit pause, knockback, haptic, UI: for each, on or off, and the one carrying the signal
- Scaling: small / medium / large event: what changes in each layer
- Tunables: <name = default, in the tunables file>
- Acceptance: <measured: response <= n frames; channels fired >= n; buffer = n> and <judged: strip beside <reference> reads as <adjective>>
```

Layers must be switchable, so a review can show that each earns its place. The adjectives here and in `north_stars.feel` are the same strings.
